# 非遗剪纸数字展陈系统 — 作品重要代码说明

## 一、工程概述

本作品基于**安路 EG4S20BG256** FPGA 实现一套非遗剪纸数字展陈终端。

- 从 TF 卡读取 BMP 位图，经 SDRAM 双缓冲调度后由 HDMI 输出 640×480 画面
- 同步输出 48kHz 音频，换图换曲
- 围绕剪纸主题实现七项扩展功能

**开发环境**：安路 TD 6.2.1
**代码规模**：61 个 Verilog 文件，16982 行

## 三、核心模块说明

### 3.1 顶点模块 `top_tf_hdmi_audio.v`

系统集成，约 1700 行。主要职责：

- 时钟与复位管理（PLL 产生 100MHz 系统时钟、25MHz 像素时钟）
- 各功能模块例化与连线
- 时钟域同步（两级触发器 + 格雷码）
- 按键消抖与功能调度

### 3.2 剪纸花边转场 `papercut_wipe.v`

**创新点之一**。换图时不使用通用淡入淡出，而是生成锯齿状"剪纸花边"从中心向外推开。

**实现要点**：
- 两路反向三角波驱动 X/Y 锯齿边界
- 全部使用位运算与比较，**不含除法器**
- 支持三种模式：左到右、上到下、中心向外（默认）

### 3.3 汉字字幕 `osd_cn_text.v` + `osd_font_cn.v`

自建 16×16 点阵字库（30 个汉字），实现电影字幕风格的双行叠加。

**描边算法**：
- 横向邻居：字模整体移位一次
- 纵向邻居：组合逻辑二次查表，**不打拍**避免错位
- 白字心 + 黑描边，无实心底块

### 3.4 音频波形 `audio_scope.v`

双缓冲 32 点采样 + 峰值音量柱。全部使用移位与比较，**零 DSP 占用**。

### 3.5 参数面板 `param_osd_show.v`

右上角常驻显示三行参数：

| 行 | 内容 | 示例 |
|---|---|---|
| 0 | 亮度 | `B 128` |
| 1 | 页码 | `P 3` |
| 2 | 轮播周期 | `T 2` |

8×8 点阵小字库，与汉字系统完全独立。十进制拆位用"比较并相减"，不产生除法器。

### 3.6 亮度对比度 `brightness_contrast_adjust.v`

- 亮度：`像素 × 亮度值 >> 8`
- 对比度：`(像素 − 128) × 对比度值 >>> 7 + 128`，饱和截断
- 参数在**帧边界锁存**，避免撕裂

## 四、按键与开关

| 硬件 | 丝印 | 引脚 | 功能 |
|---|---|---|---|
| key1 | KEY2 | B2 | 短按 = 下一张；长按 1 秒 = 上一张 |
| key2 | KEY4 | C1 | 短按 = 自动轮播 开/关 |
| key3 | KEY3 | B1 | 底部音频波形 显示/隐藏 |
| rst_n | — | A2 | 复位 |
| sw1~sw4 | — | C8/C7/C6/C5 | 轮播周期（SW1/SW2）、亮度对比度（SW3/SW4）|

**SW6 必须拨到上**（数码管才显示图号）。

## 五、编译方法

1. 用 **安路 TD 6.2.1** 打开 `td_project/HDMI1.4b_Transmitter_v1.0.al`
2. 在 FPGA Flow 面板双击 `Syn Opt`（综合优化）
3. 双击 `Phy Opt`（布局布线）
4. 在 `HDMI1.4b_Transmitter_v1.0_Runs/phy_1/` 下生成 `.bit` 文件
5. 烧录 `.bit` 到 FPGA

**编译耗时**：约 2~3 分钟（Syn + Phy 全流程）

## 七、TF 卡文件格式要求

卡上放置 4 张 BMP 图片，命名建议按扫描顺序：

```
00_01.bmp   第1张  十二生肖 / 河北蔚县剪纸
01_02.bmp   第2张  团花窗花 / 山东高密剪纸
02_03.bmp   第3张  门神祈福 / 陕西延安剪纸
03_04.bmp   第4张  福满人间 / 广东佛山剪纸
```

**BMP 规格必须严格满足**：

| 项 | 要求 |
|---|---|
| 分辨率 | 640 × 480 |
| 位深 | 24 位（无压缩）|
| 文件大小 | 921654 字节 |
| 像素偏移 | 54 |
| 压缩方式 | 0（BI_RGB）|

固件按此规格严格校验，不符合的文件会被**自动跳过**。

图片转换方法：使用 `doc/convert/convert_images_to_bmp.py`，或用任意图像软件另存为"24 位 BMP、640×480、无压缩"。

## 八、设计要点总结

**① 全硬件流水线**：无处理器参与，上电即运行。

**② SDRAM 双缓冲防撕裂**：写入与显示分属不同缓冲，读到的一定是完整帧。

**③ 多时钟域严格同步**：
- 单拍脉冲跨域：**展宽为电平 + 两级同步 + 应答握手**
- 数据跨域：格雷码编码

**④ 零除法器设计**：所有缩放、拆位、增益均用移位与常数乘法。

**⑤ 全链路软回退**：每个功能独立使能参数，置 0 即旁路回原始行为，保证永不黑屏。
